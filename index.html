README.md

MButton 是组件库内置的基础按钮组件，支持 primary / default / dashed / text / link 五种类型，small / medium / large 三种尺寸，适用于表单提交、页面跳转、危险操作确认等场景。

安装
npm install @mcp/component-library
基本用法
import { MButton } from '@mcp/components';
<MButton type='primary' size='large'>提交订单</MButton>
